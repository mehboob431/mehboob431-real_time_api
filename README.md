---->Project Overview
This project is a modern task management web application built using React with a well-structured and scalable architecture.
It includes authentication handling, task and user management, protected routes,
and reusable UI components to ensure maintainability and clean code practices. 
The application follows a modular folder structure separating contexts, components, pages, services, 
and styles, making it easy to extend and manage as the project grows. API communication is centralized, and real-time features can be integrated using socket support,
providing a solid foundation for a collaborative and responsive task management system.
